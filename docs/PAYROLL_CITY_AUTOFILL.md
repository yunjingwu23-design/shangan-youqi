# 城市政策自动填写（开发分支，待官方数据核验）

用户只需选择缴费城市、政策月份并输入工资；系统从核验过的官方政策快照填写费率、基数上下限和适用条件，不要求用户搜索或核对政策数值。单位可自行选择的公积金比例及工伤行业类别必须作为估算假设展示，不可冒充统一法定费率。

## 当前状态

自动选择、版本匹配、来源校验及分险种基数计算已实现。生产数据文件 `lib/salary/city-policy-data.json` 当前为空：此云实例的 HTTP 白名单拦截上海、北京、深圳、广州官方站点，无法取得原文进行核验。**没有填入任何猜测费率或测试数据，没有将此未完成分支发布到 main。** 现有官网计算器继续使用之前版本。

官方人社、医保、公积金和市政府域名已保存到环境联网配置草稿，保留其他既有域名。需环境设置保存/发布并生效后继续采集；无需任何数据 API Token。不要使用中转代理绕过网络策略。

## 发布城市数据的条件

1. 在允许的官方域名读取具体政策原文，记录原始文档 SHA-256、获取时间、标题、发布日期、适用范围和支持数值的原文摘录。来源必须是具体文档 URL，不能用官网首页代替核验依据。
2. 合并同一城市人社、医保、公积金文件，将生效日期交集作为该版本的有效范围。社保险种上下限不一致时使用分项 bounds，不得把养老限额误套到医保。单位选择范围、适用人员类别、阶段性降费、合并缴费情况写入 assumptions。
3. 只把已读到并核验的值录入数据文件；人工核验由维护者完成，不转交用户。未读到、未核验的版本保持未发布；不能将测试夹具、演示比例或过期版本当作当前城市政策。
4. 执行 `npm run test:city-policies`、`npm run test:calculator`、`npm run build` 及城市自动填写浏览器流程。数据未核验前不发布 main；所有条件满足后通过既有 Vercel Git 通道发布，无需数据库迁移。

## 选择与隐私

`GET /api/salary/policies` 仅返回公开政策快照，没有工资、奖金或扣除参数。个人输入仍只在浏览器计算，不写入 URL、存储或接口请求。

默认进入自动模式；自定义仅为可选高级模式。选择城市/月份缺少有效版本时隐藏估算，不复用上一城市参数、不使用演示值兜底。匹配要求政策覆盖完整月份；按该月份政策外推全年，不回算年内调标。页面显示有效期、核验日期、原文链接和估算假设。

## 验证

- `npm run test:city-policies`：政策有效期、官方域名与具体文档要求、未来核验日期、重叠版本、数据完整性、收入保留与不同险种独立限额。
- `npx playwright test tests/city-policies.e2e.ts tests/payroll-calculator.e2e.ts`：通过**仅测试时拦截的虚构政策响应**验证选择城市自动填写、工资变动重算、错误恢复、缺失与过期版本不生成结果，以及自定义模式回归。这些结果不证明已获取任何真实城市政策。
