# 薪酬 / 社保计算器

路径 `/jobs/salary/calculator`，归属「找岗位 → 查薪资」。查薪资页及 Offer 对比页均提供入口，保持四个一级导航和官方 Logo。公开使用，无需新增环境变量或 SQL 迁移。

## 计算范围

适用于中国内地居民个人、全年在同一单位任职、固定月薪和每月扣除稳定的工资薪金估算。本版本支持 2019–2027 年。模型不处理多雇主、中途入离职、非居民、劳务报酬、年度汇算退补税、单位超限公积金转应税收入等情况。

- 所有金额为人民币，输入最多两位小数。内部按整数分计算，每个险种双方缴费分别舍入到分；不能将所有比例合计后仅舍入一次。
- 社保公共基数、公积金独立基数：在输入的下限和上限间校正。未填上下限时不校正；单项核定基数覆盖公共基数及其上下限，按已核定最终值填写。
- 养老、医保、失业、工伤、生育及公积金分项显示个人和单位比例、有效基数和月缴费。工伤和生育不设个人缴费；生育并入医保时单位生育比例必须为零。医保个人固定附加额单列。
- 公积金比例限双方各 0–12%。个人缴费默认作为专项扣除；城市基数税前扣除限额或其他不允许扣除情形，由使用者通过「社保公积金可税前扣除额覆盖」填写合法金额，不得超过实际个人缴费。
- 每月减除费用 5,000 元，专项附加扣除及其他依法可扣除项目按月累积。其他税前扣除仅改变税基，不另外从到手现金中扣钱。
- 应税工资 = 累计工资 − 每月减除费用累计 − 合法个人社保/公积金累计 − 专项附加扣除累计 − 其他税前扣除累计，下限为零。工资预扣税 = 累计应预扣税 − 已预扣税，下限为零。每月税额因此可能不同。
- 固定薪资月数支持 12–24；超过 12 薪的部分在 12 月作为普通工资发放和计税。奖金单独输入，也假设 12 月发放，不能重复填入固定月数。
- 全年一次性奖金仅在符合条件且本年未使用该方式时可选单独计税；以奖金÷12 找月度税率，税额为奖金×税率−月度速算扣除数。并入综合所得与单独计税均展示模型结果，不假定后者总是更省税。
- 年净现金 = 年税前现金 − 12 个月个人缴费 − 个税。单位用工成本 = 年税前现金 + 12 个月单位缴费。双边公积金单列为账户入账，不计入到手现金。

## 政策与参数来源

综合所得采用自 2019 年适用的七级表：36,000 / 144,000 / 300,000 / 420,000 / 660,000 / 960,000 元，税率 3 / 10 / 20 / 25 / 30 / 35 / 45%，速算扣除 0 / 2,520 / 16,920 / 31,920 / 52,920 / 85,920 / 181,920 元。

依据：《中华人民共和国个人所得税法》（2018 年修正）、国家税务总局公告 2018 年第 61 号、财政部 税务总局公告 2023 年第 30 号。全年一次性奖金单独计税配置适用至 2027 年底。页面提供国家税务总局及人社部政策检索入口，不声称这些首页是具体城市的官方数据源。

没有自动加载或声称实时同步任何城市政策。默认比例明确标记为演示参数，基数上/下限留空。输入城市名称仅作为备注，不会改变计算规则。使用者应按公司工资条、当地人社及公积金中心当年有效规定调整参数。不要将未经核验的城市标准硬编码为官方默认值。

## 隐私与验证

输入不进入 URL、不发送计算 API、不写入 Cookie、localStorage 或 sessionStorage，也不与匿名薪资投稿自动关联。正常页面访问及既有登录框架继续按全站配置运行。

- `npm run test:calculator`：年度税率全部档位、奖金临界点、累计预扣、个人与单位成本分离、独立基数、单项覆盖、分项舍入、医疗附加、生育合并、13 薪与奖金分流、低收入情形、无效输入、原导航归属。
- `npx playwright test tests/payroll-calculator.e2e.ts`：匿名访问、入口、参数变更与本地计算、错误恢复、年终奖条件、上下限错误和移动端横向滚动。
- 正式发布前运行 `npm run typecheck`、`npm test`、`npm run build`。浏览器验证使用构建后的 `npm start`，避免 Next 开发浮层干扰。
