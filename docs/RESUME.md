# 智能简历编辑器：首批核心工具

简历工具提前为首批核心工具，与 AI 面试复盘并行规划。先交付真实编辑、分页与文字型 PDF 导出，再改善模板还原；不以 AI 接入为前置条件。

## 已实现流程

`/resume` → 用户确认临时处理授权 → 上传 DOCX / 文字型 PDF → 提取原文 → 规则识别个人信息、教育、经历、项目、校园、技能等模块 → 用户校对 → 左侧修改、右侧真实 A4 分页 → Chromium 导出 PDF。

- DOCX：Mammoth 提取文字，ZIP 预检限制解压总大小与条目数；不执行宏，不访问外部链接。对表格、多栏与文本框给出提示。尽可能参考可识别的页边距和字体类别，不承诺样式完整保留。
- PDF：unpdf / PDF.js 读取文字与坐标；限制页数和体积，检测重复列间距时尝试先左后右展开。扫描件和含无文字页的混合文件拒绝，不做 OCR。密码保护文件给出错误。
- 模块：标题规则识别；姓名不确定时留空，不猜身份；没有标准标题时保留完整待校对原文。不调用 AI 进行事实补全。
- 编辑：姓名、联系方式、意向、模块标题/日期/正文、增删与排序；思源黑体/宋体，字号、行距、段距、页边距即时重排。
- 版本：IndexedDB 自动保存、复制、重命名、切换、删除，最多 30 个。保存失败明确提示，不显示伪成功。
- 分页：按真实浏览器字号和字体测量，长段落二分切分跨页，保留全部字符。A4 真实尺寸，页码与多页预览；超过 20 页或水平溢出时禁用导出，不静默裁切。
- 导出：同一份 `document.ts` 生成预览与导出 HTML/CSS。服务端 Playwright Chromium `page.pdf`，A4、字体嵌入、文字层、无截图栅格化。

## 隐私与权限边界

当前网站没有真实账号认证，因此这是**浏览器私密工作区，不是云端个人账号存储**。

- 版本与导入原文仅保存于同源浏览器 IndexedDB，不写入服务器数据库、对象存储或公开 URL。
- 用户选择导入前需确认将文件发送到本站临时解析；导出时也会发送当前版本正文用于临时渲染。原文件不保存、不进入应用日志；处理结束后不保留服务器简历记录。
- `/api/resume/session` 建立 HttpOnly、SameSite=Strict、HTTPS Secure 的匿名短期处理会话；处理接口必须匹配会话 CSRF token 和请求 Host/Origin。它防止跨站滥用，不等同于微信登录或真实用户身份。
- `/api/resume/import` 和 `/export`：未建立会话返回 401，跨来源或 token 不匹配返回 403/401；响应均 private/no-store。
- 导出浏览器禁止网络请求，原文统一 HTML 转义；预览 iframe 使用 opaque-origin sandbox + CSP，仅通过 nonce 校验的 postMessage 回传排版结果。
- 每实例限制每会话每分钟 12 次处理、同时 2 个导出。多实例全局限额、正式账号认证、审计与完整个人数据权限需要下一阶段独立实现。公开大规模开放前启用平台级限流。
- 删除版本同时移除该版本原文。个人中心“删除本地演示数据”也清空简历库。已下载到电脑的文件需用户自行删除。
- 同一浏览器同一域名的使用者共享本地存储；共享电脑请删除数据，不宣称具有不同登录账号之间的隔离。跨设备同步必须等待真实认证与 RLS。

## 运行与 Vercel

当前不需要数据库或 AI 密钥。

- 本地 Linux：默认查找 `/usr/bin/chromium`；可设置服务端 `RESUME_CHROMIUM_EXECUTABLE_PATH` 指向本机 Chromium 可执行文件。
- Vercel：使用 `@sparticuz/chromium` 随包二进制，使用 Node.js runtime，导入/导出函数 `maxDuration=60`；Next 配置显式追踪 Chromium 包与本地字体文件。没有依赖运行时公网下载浏览器或字体。
- 文件最大 3MB（为 serverless 请求体上限留余量），PDF 最多 12 页；文字总量最大 80000 字符，单模块 18000 字符；导出最多 20 页。
- 字体来自 Fontsource 的 Noto Sans SC / Noto Serif SC 400 WOFF2，SIL OFL 许可证随文件提供。按简历实际字符选择 Unicode 分片，预览和导出用同一组嵌入字体。
- `.vercelignore` 保留 `public/fonts`；没有写入服务端密钥。浏览器路径是本地可选变量，Vercel 不要填写本机路径。

## 测试及准确度边界

测试夹具位于 `tests/fixtures/resume`。4 个 DOCX（中文单栏、表格、英文、长文），4 个 PDF（单栏、双栏、多页、纯图片扫描件）均为匿名合成的常见真实业务版式；**不是已获得用户授权的真实个人简历集合**。

- 单元：文字保留、教育/经历/项目/技能模块、未知标题回退、文件签名/大小限制、扫描拒绝、HTML 注入转义、样式约束。
- 浏览器：DOCX 上传 → 修改姓名/日期/字体/间距 → 预览变化 → 下载 → PDF.js 重新抽取文字、页数、A4 尺寸；最后一段长文保留；版本复制刷新删除；文字 PDF 导入；手机布局；会话与跨来源拒绝。
- 运行 `npm test`、`npm run test:e2e -- resume.spec.ts`。PDF 样本可通过 `node --import tsx tests/generate-resume-pdfs.ts` 重新生成（需 Chromium）。

这些检查不等于任意模板解析准确率。复杂文本框、左右栏交错、图文、竖排、跨页表格、特殊字形等仍需逐项人工校对；后续应在获得授权的真实匿名化简历集合上统计字段准确率、阅读顺序和版式差异。
