# 信息架构与导航重构

本次重构先确定站点地图与交互规则，再复用现有组件实施。数据库、内部 user_id、RLS、存储桶和既有记录保持原状；不执行清库、数据搬迁或重复导入。

## 首页布局

1. 官方 Logo、四个一级导航、账号入口。
2. 简洁主标题与全站搜索：岗位/公司别名、公开指南、登录用户自己的记录；结果按内容类型分组。当前为检索匹配，不冒充 AI 对话。
3. 「今天想先做哪一步？」四张行动卡：找机会、管理求职、准备面试、阅读面经，分别进入模块首页。
4. 最新精选岗位：只使用已发布目录，未有正式数据时明确为样品。
5. 登录用户近期事项：本人最近更新的投递记录；无记录显示开始行动的空状态。没有日期数据时不虚构提醒。

不在首页平铺所有二级功能。页脚不出现后台入口。

## 持续导航与移动端

- 根布局统一提供导航，覆盖首页、模块、岗位详情、简历编辑、登录、录音上传、进度、校对和报告等具体页面。
- 桌面顶部保留四个一级入口；当前模块高亮。每个一级入口点击后回到模块首页。
- 模块内部横向二级导航可滚动；当前功能高亮，查询参数区分招聘类别。面包屑显示首页 → 模块 → 当前功能/详情。
- 详情/编辑页提供返回上一页；无站内上一页时回到对应模块首页。
- 手机顶部保留 Logo 与账号，底部固定四个核心入口；内容与按钮预留安全区域，不遮挡上传、保存等操作。
- 简历、笔记和表单的未保存文字按认证用户隔离暂存在当前浏览器标签页，导航离开/返回后恢复；保存仍需调用原服务端接口。退出、清空个人数据、注销时清除暂存。待上传文件仅在当前标签页内存保留，站内导航返回可继续使用；刷新或关闭会提示重新选择。授权勾选需要重新确认，尚未提交的录音不会显示为已上传。
- 登录后的返回地址通过白名单校验，公开内容不因浏览而要求登录。

## 后台

`/admin` 及子页使用独立导航：内容运营、服务运营、数据中心、系统管理。所有页面继续检查 siteManager 权限，普通用户不能通过输入 URL 或调用 API 绕过。内容运营保留岗位管理、JD 文本录入、发布核验；其他未实现的能力保留需求和明确状态，岗位统计从现有目录实时读取；服务订单与权限管理界面仍标记待开发。JD 文本导入支持 TXT，追加到职责后由运营核对并保存。

## 保留需求与状态

- 现有可用：邮箱登录、横向投递表、收藏、简历分块编辑/预览/Word 与 PDF 导出、PDF/DOCX 原文件上传与原版文字编辑、公开指南、文字面试练习、手动笔记、岗位运营。简历具体格式边界见 [RESUME_FILES.md](RESUME_FILES.md)。
- 条件开放：录音上传/异步转写/AI 复盘沿用 INTERVIEWS_ENABLED 配置；未开放时页面说明并保留主导航。
- 待开发/运营准备：完整 Office 排版编辑、扫描件 OCR、AI 简历解析/改写、招聘日历、自动日程提醒、准备计划、全网雷达、授权商城、真人导师预约。保留对应模块位置及需求说明，不提供伪造内容、下单或成功反馈。

## 验收路径

1. 新用户：首页 → 找岗位 → 转正实习 → 岗位详情；查看明确的留用依据或样品标识，不需登录。
2. 已登录用户：首页 → 我的求职 → 修改投递状态；模块二级导航 → 我的简历 → 修改/预览/保存；离开再返回未保存稿保持，原记录不丢失。
3. 面试用户：首页 → 面试中心 → AI 复盘 → 上传；或 → 真人 Mock → 查看真实开放状态/保存意向；录音链路与每个具体页面均保留导航。

## 部署与验证

IA 重构本身没有新增环境变量或 SQL 迁移，不需要再次配置云环境。后续简历增强也沿用已有环境变量，另提供可选私有桶加固迁移，见 [RESUME_FILES.md](RESUME_FILES.md)。沿用已配置的 Supabase、原账号迁移与前一轮岗位目录迁移，不重置生产数据。GitHub main 推送后由现有 Vercel 项目部署，公网地址保持 `https://shangan-youqi.vercel.app/`。本环境网络策略不允许访问 Vercel API/线上域名，因此线上 Ready 状态仍以平台实际部署为准。

验证使用本地真实 Auth、PostgreSQL、私有 Storage、Mailpit 与 Chromium。覆盖三类用户路径、桌面/手机/900px 平板布局、旧链接、草稿恢复、简历版本保存/删除、后台 JD 导入和角色隔离。搜索的个人结果只显示本人记录；只读导航前后逐条比较数据库，原记录与内部 ID 不变。测试详情见 [TESTING.md](TESTING.md)。

真实 OpenAI 调用、线上邮件送达和真人导师履约不属于已通过项；本轮没有申请 Key、替用户付款或开放未准备好的服务。
